# Contract: ядро `svgshaper`

Публичная библиотека. Исполнитель вызывает `async`-функции своим runtime.
Публичные типы не ссылаются на Tokio и Bevy. Растеризацию выполняет процесс,
запущенный внутри ядра через `std::process::Command`.

Нормативное поведение — `spec.md`. Модель полей — `data-model.md`.

## Вход

`convert(request, stop) -> impl Future<Output = Result<ConversionReport, RequestError>> + Send`

- `request`: `ConversionRequest`.
- `stop`: `StopFlag`. Пока флаг опущен, запрос идёт по источникам по очереди.
  `stop.request()` можно вызвать из другого потока. После сигнала future
  завершается отчётом, а не обрывом без итогов.

`RequestError`: `InvalidSize`, `EmptySources`, `InvalidName`,
`DestinationUnavailable`, `ConverterUnavailable`. При этой ошибке новых
файлов нет. `ConverterUnavailable` — программу из поля `converter` нельзя
запустить.

## Выход

`Ok(ConversionReport)` означает, что запрос принят и каждый взятый в работу
источник имеет ровно один итог: успех с путём, неуспех с причиной из
`data-model.md` или `Stopped`.

Успешный PNG:

- лежит по пути из шаблона внутри папки назначения;
- имеет ровно запрошенные ширину и высоту;
- на произвольном SVG публикуется, когда процесс завершился с кодом 0 и IHDR
  совпал с запросом. Отдельной проверки «эффект тихо пропал» нет;
- на контрольном наборе из spec SC-007 автопроверка области подтверждает
  фигуру, контур, заливку, обводку, прозрачность, градиент, простой текст
  системным `sans-serif`, фильтр, маску, обрезку, маркер и начальный вид
  анимации. Попиксельное равенство эталону не требуется. Файла шрифта рядом
  нет;
- прозрачные области контрольного файла остаются прозрачными.

## Процесс и запись

Программа по умолчанию — `rsvg-convert`. Запуск без интерпретатора оболочки:

```text
rsvg-convert --width {width} --height {height} --format png --output {temp} {source}
```

`--keep-aspect-ratio` и `--background-color` не передаются.

1. Конечный путь занимается в процессной таблице, либо источник получает
   `ConcurrentWrite` и процесс не запускается.
2. `Command::spawn` пишет PNG во временный файл в папке назначения. Пока
   процесс жив, `StopFlag` может завершить его через `Child::kill`.
3. После нулевого кода выхода ядро читает IHDR. Размер обязан совпасть с
   запросом. Иначе временный файл удаляется, причина — `CannotDraw`.
4. Временный файл переименовывается в конечное имя только когда PNG цел и
   размер совпал.
5. Неуспех и остановка до переименования удаляют временный файл. Прежний
   конечный файл остаётся.

`replace = false` и уже существующий конечный файл дают `NameTaken` без
открытия этого файла на запись.

## Чего контракт не делает

- Не вызывает `sh`, `bash` и не собирает одну строку команды.
- Ядро не читает другие файлы и сетевые адреса и не передаёт их в аргументах.
  Относительную ссылку, которую откроет сам растеризатор, контракт не
  запрещает.
- Не обходит вложенные папки.
- Не сохраняет пропорции отдельным режимом.
- Не координирует запись с процессом, который не вызвал это ядро.
